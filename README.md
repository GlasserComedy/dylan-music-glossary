# Dylan Music Lexicon (no YT previews)

I want to build a website with the working title, "The Dylan Lexicon: A Glossary of Musical Terms, Illustrated Through the Songs of Bob Dylan". I'm attaching an image with the basic idea. The main idea is to have a website that facilitates learning about music with Bob Dylan as the springboard. The main image is a mid-60s illustration of Dylan's head, with musical terms surrounding it. When one clicks on that term - say, "rhythm" - a definition of that term will appear on the right-hand side of the screen, with a musical example underneath, with a play-button from Spotify. An added feature would be that in order to get to the next set of terms, you click on his head which rotates slightly. Eventually, the head spins around again once you've clicked through all of the terms. There's also an alphabet underneath if one wants to look up a term alphabetically. That's the basic idea.
