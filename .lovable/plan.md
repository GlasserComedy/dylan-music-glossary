# Mobile category constellation

## Direction

Bring the entered phone view closer to desktop: keep the compact header and All Terms access, then make the Dylan head the visual center of an airy field of newspaper-clipping category labels.

## Build

- Replace the default mobile A–Z list with a touch-friendly category constellation around a smaller Dylan head.
- Keep category labels readable and evenly distributed, using the existing typewriter clipping style.
- Tapping a category transitions to that category's terms in a clean mobile list; provide a clear way back to all categories.
- Keep alphabet filtering, search, term pages, coffee, and contact behavior intact.
- Preserve the current opening screen and desktop design.

## Technical details

- Add a dedicated mobile category composition rather than shrinking the desktop collision layout.
- Reuse the existing semantic paper, ink, and accent tokens and current two-font system.
- Verify the entered view, category selection, term opening, and back navigation at phone size.
