# Fit the full desktop term cloud beside definitions

## Direction

Use the empty space beside the narrow definition panel instead of shrinking and translating the entire map as one oversized canvas.

## Build

- When a definition is open, give the head and category cloud a dedicated left-side stage that ends before the definition panel.
- Recalculate the cloud inside that available stage so every category term remains fully on-screen and clickable.
- Keep the head large and centered within the cloud rather than scaling the whole composition down excessively.
- Preserve the current category layout and full-size composition when no definition is open.
- Leave mobile unchanged.

## Verification

- Test both a small and a large category on desktop.
- Confirm every term label is fully inside the viewport, none sits beneath the definition panel, and each remains clickable.
